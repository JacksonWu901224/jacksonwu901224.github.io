# Linux 常用指令整理

> 適合日常開發、訓練模型、系統管理使用

---

## 1. 進程管理

| 指令 | 說明 |
| ------ | ------ |
| `ps -ef` | 顯示所有進程（完整格式） |
| `ps -ef \| grep 關鍵字` | 過濾特定進程 |
| `top` / `htop` | 即時查看系統資源與進程 |
| `kill <PID>` | 正常終止指定進程 |
| `kill -9 <PID>` 或 `kill -KILL <PID>` | 強制立即終止進程（最強） |
| `killall 進程名` | 依名稱終止所有同名進程 |
| `pkill 關鍵字` | 依名稱關鍵字終止進程 |
| `nohup 指令 &` | 背景執行，登出後繼續運行 e.g. nohup python run_stage1.py > stage1_train.log 2>&1 & |
| `jobs` | 查看目前背景工作 |
| `fg` / `bg` | 將工作切換到前景 / 背景 |

## 2. GPU 監控（gpustat）

| 指令 | 說明 |
| ------ | ------ |
| `gpustat -p -i 1` | 每秒更新，顯示進程 PID |
| `gpustat -c -i 1` | 每秒更新，顯示使用的 CUDA 裝置 |
| `gpustat -u -i 1` | 每秒更新，顯示使用者名稱 |
| `gpustat -i 1` | 每秒更新一次 GPU 狀態 |
| `watch -n 1 gpustat` | 另一種每秒刷新的方式 |
| `nvidia-smi` | NVIDIA 官方 GPU 狀態工具 |
| `nvidia-smi -l 1` | 每秒自動刷新 |

## 3. 日誌與檔案即時查看

| 指令 | 說明 |
| ------ | ------ |
| `tail -f training.log` | 即時追蹤日誌（最常用） |
| `tail -n 100 training.log` | 顯示最後 100 行 |
| `tail -f -n 50 training.log` | 顯示最後 50 行並持續追蹤 |
| `less +F training.log` | 類似 `tail -f`，可按 `Ctrl+C` 後用方向鍵查看 |
| `head -n 20 檔案` | 顯示前 20 行 |
| `cat 檔案` | 一次顯示整個檔案內容 |
| `less 檔案` | 分頁查看檔案（方向鍵上下，`q` 離開） |
| `more 檔案` | 簡單分頁查看 |

## 4. 檔案與目錄操作

| 指令 | 說明 |
| ------ | ------ |
| `ls -lah` | 詳細列出檔案（含隱藏檔、人類可讀大小） |
| `ls -lt` | 依修改時間排序 |
| `cd 目錄` | 切換目錄 |
| `pwd` | 顯示目前路徑 |
| `mkdir 目錄` | 建立目錄 |
| `mkdir -p 目錄1/目錄2` | 建立多層目錄 |
| `touch 檔案` | 建立空檔案，或更新檔案時間戳 |
| `cp 來源 目標` | 複製檔案 |
| `cp -r 來源目錄 目標` | 複製整個目錄 |
| `mv 來源 目標` | 移動 / 重新命名 |
| `rm 檔案` | 刪除檔案 |
| `rm -rf 目錄或檔案` | **強制遞迴刪除**（危險，無法復原） |
| `rm -i 檔案` | 刪除前會詢問確認 |
| `find . -name "*.log"` | 尋找符合條件的檔案 |
| `find . -type f -size +100M` | 找出大於 100MB 的檔案 |
| `du -sh *` | 查看目前目錄各項目大小 |
| `du -sh .` | 查看目前目錄總大小 |
| `df -h` | 查看磁碟空間使用情況 |
| `tree` | 以樹狀結構顯示目錄（需安裝） |

## 5. 文字編輯器

| 指令 | 說明 |
| ------ | ------ |
| `nano 檔案` | 簡單易用的文字編輯器（推薦新手） |
| `vim 檔案` / `vi 檔案` | 功能強大的編輯器 |
| `code 檔案` | 用 VS Code 開啟（需安裝） |
| `cat > 檔案` | 直接建立並寫入內容（`Ctrl+D` 結束） |
| `echo "內容" > 檔案` | 寫入內容到檔案（覆蓋） |
| `echo "內容" >> 檔案` | 附加內容到檔案末尾 |

### nano 常用快捷鍵

- `Ctrl + O`：儲存
- `Ctrl + X`：離開
- `Ctrl + W`：搜尋
- `Ctrl + K`：剪下整行
- `Ctrl + U`：貼上

### vim 基本操作

- 按 `i` 進入插入模式
- 按 `Esc` 回到普通模式
- `:w` 儲存
- `:q` 離開
- `:wq` 儲存並離開
- `:q!` 強制離開不儲存

## 10. 推薦工具（訓練 / 遠端工作常用）

| 指令 / 工具 | 說明 |
| ------------- | ------ |
| `tmux` | 終端多工，斷線後程式繼續跑（強烈推薦） |
| `screen` | 類似 tmux 的終端管理工具 |
| `htop` | 比 top 更好用的進程監控 |
| `ncdu` | 互動式磁碟空間分析工具 |
| `rsync` | 強大的檔案同步工具 |

### tmux 基本操作

- `tmux`：開啟新 session
- `Ctrl + B` 然後按 `C`：新建視窗
- `Ctrl + B` 然後按 `D`：暫時離開（detach）
- `tmux attach`：重新連回
- `Ctrl + B` 然後按 `%`：左右分割
- `Ctrl + B` 然後按 `"`：上下分割

## 使用小提醒

1. **`rm -rf` 非常危險**，執行前請再三確認路徑，建議先用 `ls` 確認。
2. 訓練模型時強烈建議使用 **tmux** 或 **screen**，避免 SSH 斷線導致程序中斷。
3. `gpustat` 安裝方式：`pip install gpustat`
4. 不確定指令用法時，優先使用 `man 指令` 或 `指令 --help`。
5. 重要操作前可以先備份：`cp -r 原目錄 原目錄_backup`
